# 计算机网络核心概念

## TCP 与 UDP 的区别

TCP：面向连接、可靠传输，通过三次握手建立连接，保证数据按序到达。
UDP：无连接、不可靠，但开销小、延迟低，适合音视频流媒体。

三次握手：客户端发送 SYN，服务端回 SYN-ACK，客户端再回 ACK，连接建立完成。

## 常见端口

- 80：HTTP 明文网页服务
- 443：HTTPS 加密网页服务
- 22：SSH 远程登录
- 3306：MySQL 数据库默认端口

## HTTP 状态码分类

| 类别 | 含义 |
|---|---|
| 2xx | 请求成功 |
| 3xx | 重定向 |
| 4xx | 客户端错误 |
| 5xx | 服务端错误 |

Q: 什么是 MTU？
A: Maximum Transmission Unit，链路层一次能传输的最大数据包大小，以太网通常为 1500 字节。

## DNS 解析过程

DNS 采用分布式层级结构，从根域名服务器开始，依次查询顶级域服务器和权威域名服务器，
最终获取目标域名对应的 IP 地址。本地会缓存解析结果以减少查询开销。

### 递归查询与迭代查询

递归查询：由 DNS 服务器代为完成全部查询，客户端只等待最终结果。
迭代查询：DNS 服务器只返回下一级服务器地址，由客户端自己继续查询。
